# 01 · 产品定位与商业模式

## 痛点

贵州优质景点高度分散在各地州（安顺、黔东南、黔南、黔西南、遵义、铜仁……）。游客的典型路径是：在小红书种草 → 自由行抵达 → 发现几天行程大半花在跨城大巴和转车上，"几天游玩，最后都是在坐车从一个城市到另一个城市"。

## 定位

**合理安排散客出行的贵州私域旅游平台。**

针对来贵州的自由行散客，直接提供：

- **拼团组游**：同路线散客拼小团，摊薄车费导游费
- **AI 定制行程**：在预算 / 时间 / 服务等级约束下自动生成环线方案
- **全程服务包**：拼车接送（行李直达下一站酒店）、旅行保险、无人机航拍跟拍、按游玩类型推荐的地道美食与餐饮

## 商业流程 ↔ 游戏机制映射

游戏是商业模式的"前端故事层"——每个业务节点在游戏里都有一个叙事化身，用于政府汇报、路演和流量承接阶段的演示：

| 商业流程节点 | 游戏里的化身 | 实现状态 |
|---|---|---|
| 填写偏好 → AI 生成行程 | 行程单 2.0：主题筛选、环线规划、拼车 vs 自助省时对比 | ✅ 已实现 |
| 发布拼团 / 浏览拼团 | NPC 拼车告示：送达信件后弹出"班次/车型/还差 N 人成团/价格" | ✅ 已实现（纯叙事，无后端） |
| 资源匹配（司机/导游/摄影/安全员） | NPC 服务角色化：拼车师傅老杨、航拍小哥小韦、美食向导等 13 人 | ✅ 已实现 |
| 成团确认 → 出行服务 | 送信任务链：跑完一圈环线 = "环线跑通" | ✅ 已实现 |
| 评价结算 → 信用更新 → 裂变 | 明信片 + 风物收集度、分享卡片导出（私域召集拼友） | ✅ 已实现（收集度/分享卡片） |

## 渠道路径

1. **流量端**：小红书 / 抖音内容种草（游戏本身即传播素材）
2. **承接端**：企微 + 小程序私域，游戏落地页嵌入引导入群
3. **履约端（先人工后系统）**：用表单 + 微信群人工跑 3~5 单真实拼车，验证供给与定价，再决定是否开发系统化拼团/支付

## 合规提示（重要）

- **资金托管**涉及支付牌照与旅行社业务资质，预收团费有监管要求——早期用"门票/用车代订 + 本地向导服务"的轻模式，避免碰预付费资金池
- **保险**走持牌保险经纪合作分销，不自营
- **无人机航拍**需遵守景区空域管制（中国天眼等区域禁飞），文案与玩法中注意表述

## 政府报告叙事弹药

- 贵州是长征国家文化公园重点建设区，红军长征足迹遍及全省 9 个市州 60 多个县，省级战略即"串点成线"——与本产品"环线串联"逻辑同构
- 遵义会议纪念馆 2025 年接待观众 853.49 万人次；贵阳"红飘带"长征文化数字艺术馆累计接待超 200 万人次——"数字化 + 红色文化"是已验证的省级标杆路线，本产品是其延伸
- 村超（榕江）：出圈以来吸引 1669 万余人次观赛、带动旅游综合收入约 190 亿元——现象级流量如何承接，正是本平台的答案
