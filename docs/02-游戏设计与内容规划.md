# 02 · 游戏设计与内容规划

## 参考原型：Abeto《Messenger》调研结论

- **交互逻辑**：玩家在一颗可自由奔跑的迷你星球上替居民送信，信件引导玩家环游全岛；送达触发对话与收集，世界随进度逐渐鲜活。核心是"送信任务链 + 收集 + 世界活化"三件套。
- **渲染管线**：three.js + 低多边形美术。球面星球（IcosahedronGeometry 细分 + 顶点色 + flatShading）、InstancedMesh 批量散布植被、Canvas 动态纹理（瀑布/名牌）、阻尼跟随相机。无重型资源，纯前端即可承载。
- **可行性结论**：该体验的 90% 可在纯前端复刻，无需自建引擎或后端；剩下的 10%（真实用户数据、订单）属于业务后端，与游戏表现层解耦。

## 核心循环

```
接信（NPC）→ 跟随金色箭头穿越星球 → 送达（读信，人情故事）
    → 沿途打卡景点（明信片）→ 集满解锁"我的贵州环线"行程单
    → 送完第 10 封信：环线跑通 + 烟花结局
```

设计意图：玩家跑完一圈，就直观理解了产品逻辑——**十个目的地，一条环线，贵州不再分散**。

## 已实现的体验系统

- **送信任务链**：13 封人情味信件沿环线接力（首尾相接）；头顶金色箭头指路；HUD 状态条；完成触发"环线跑通"结局 + 烟花
- **NPC 服务角色化**：13 个 NPC 各有身份（拼车师傅老杨、航拍小哥小韦、守门员阿果、绣娘阿仰……），送达信件后弹出该站拼车/服务告示（班次、车型、还差几人成团、价格）——商业流程的叙事化身
- **明信片收集**：打卡弹出手账风明信片，13 张集齐解锁行程单；每张附**非遗 + 美食风物**（安顺地戏面具/酸汤鱼/赤水晒醋/宫保鸡丁……），行程单统计风物收集度
- **环线行程单 2.0**：贵阳集散、按真实地理排序；拼车 vs 自助换乘时间对比（全程 31h vs 57h，省约 26 小时）；主题筛选（全部/山水/民族/红色）；每站"顺路可加"二级站点；红色印记专线（黎平会议/苟坝/猴场/息烽/红飘带）；服务徽章（拼车/保险/航拍/美食）
- **分享卡片**：一键 Canvas 生成"我的贵州环线"图片（站点印章格 + 省时统计 + 口号），自动下载 PNG，供私域传播召集拼友
- **世界活化**：≥4 张明信片出现蝴蝶、光照变暖；≥8 张夜空放烟花
- **空间音效**：lo-fi 竹笛 BGM + 环境音循环；瀑布/篝火随距离二次方衰减；一键静音
- **手感**：加速度曲线移动、Space 跳跃、阻尼跟随相机
- **存档**：localStorage 保存打卡与任务进度
- **移动端**：虚拟摇杆 + 互动按钮、自适应 HUD、触屏设备植被密度自动减半

## 扩展规划（内容分层原则）

**星球容量原则：核心地标 ≤ 13~14 个。** 超出的一律放进行程单"顺路可加"二级站点展示，不占星球空间。

### 已落地的扩展（13 站版）

- 四渡赤水渡口（红色 + 赤水河谷绿游融合）、榕江村超（现象级流量 IP 彩蛋）、织金洞（溶洞视觉差异化）已上星球并进环线
- 黎平会议会址、苟坝会议会址等进入行程单"红色印记专线"二级站点
- 马岭河峡谷、赤水丹霞、百里杜鹃、海龙屯等作为"顺路可加"进入行程单

### 后续候选

- **青岩古镇**——距贵阳市区 30 分钟，现实环线的"抵达日/返程日"顺路点，强化集散枢纽叙事
- 百里杜鹃（季节事件：3–5 月星球上开花）
- 非遗/美食图鉴独立图鉴页（目前风物附在明信片上，可升级为收集册）
- NPC 服务角色化深化：对话气泡多轮交互，直接跳转企微/小程序下单入口（需渠道就位）
