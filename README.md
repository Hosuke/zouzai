# 黔行星球 · Guizhou Mini Planet

一颗装下贵州山水的浏览器迷你星球。玩家奔跑在低多边形 3D 星球表面，沿真实地理环线送信、打卡 13 个贵州标志性目的地（含 3 个红色站点与村超彩蛋），集齐风景明信片与非遗美食风物，解锁属于自己的"贵州环线行程单"，并可一键生成分享卡片去私域召集拼友。

它是「黔行星球」私域旅游平台的**前端故事层**：用游戏讲清"十个目的地、一条环线"的产品逻辑，承接小红书/抖音流量进入私域。

- **定位**：解决"贵州景点分散、散客几天都在坐车"的出行痛点
- **形态**：纯前端网页游戏（零构建、零依赖安装），可嵌入任何落地页/小程序 WebView
- **参考原型**：Abeto《Messenger》(messenger.abeto.co) 的送信环游玩法，纯前端复刻并本土化

## 快速开始

无需安装任何东西，起一个静态服务器即可：

```bash
cd app
python3 -m http.server 8791
# 打开 http://127.0.0.1:8791/
```

## 调试参数（URL 查询串）

| 参数 | 作用 |
|---|---|
| `?auto=1` | 跳过开始页直接进入游戏 |
| `?tp=0`~`?tp=12` | 传送到第 N 个景点附近（便于测试） |
| `?card=0`~`?card=12` | 直接打开第 N 张明信片 |
| `?plan=1` | 以"已解锁 6 站"状态打开行程单 |

可组合：`/?auto=1&tp=0`

## 存档

进度（已打卡景点 + 送信任务进度）自动保存在浏览器 `localStorage`（键：`qx-save-v1`），刷新不丢。清除浏览器数据即重置。
